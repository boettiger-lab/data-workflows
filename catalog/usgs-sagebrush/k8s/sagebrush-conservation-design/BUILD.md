## Jobs, in order

| step | manifest | notes |
|---|---|---|
| bucket | `sagebrush-conservation-design-setup-bucket.yaml` | generated; run first (new bucket) |
| stage raw | `sagebrush-conservation-design-stage-raw.yaml` | hand-rolled: download, checksum, unpack, exact histograms |
| COG ×6 | `<period>/…-preprocess-cog.yaml` | generated by `generate.sh`, resampling patched to `nearest` (datasets#272) |
| COG histograms | `sagebrush-conservation-design-cog-histogram.yaml` | hand-rolled validation |
| hex ×6 | `<period>/…-hex.yaml` | generated; res 10, parents 9,8,0, `mode`, `--nodata 0`, `--h0-cells 9,19,20,36`, `--chunk-resolution 2` (196 chunks) |
| merge ×6 | `<period>/…-merge.yaml` | generated; paths patched into `hex/period=<p>/` (datasets#172) |
| spot check | `sagebrush-conservation-design-hex-spotcheck.yaml` | hand-rolled validation |

`generate.sh` regenerates every per-period directory and applies the two declared deviations.
Hex jobs ran one at a time. The orchestrator `workflow.yaml` files are generator output and
were not used; the steps were applied individually.

**Sizing, measured.** COG warp: ~3–4 min per layer. Hex: the 2017-2020 run used the generator
default 32Gi; `kubectl top` peaked near **2.1 GiB** per pod (4 workers, res-2 chunks), so the
other five periods ran at 8Gi. Each period's hex took ~14 min at parallelism 40 with no pod
failures. Merge: ~45 s per period.

## WGS84 COGs

70,993 × 55,154 px at 0.000332051° (the full Albers rectangle, not just the biome), Byte,
NoData 0, DEFLATE, overview resampling MODE, 121–126 MB each. Full-grid histograms of the
warped COGs contain only {0,1,2,3}, so nearest-neighbour kept every class code.
