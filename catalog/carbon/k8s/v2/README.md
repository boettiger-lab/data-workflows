# Carbon v2 Processing Notes

Source: Zenodo 17645053 (Conservation International, 2025 release)
Bucket: `public-carbon`

## Canonical layout (post-curation, data-workflows #330)

- **Hex (canonical):** top-level `public-carbon/{dataset}/hex/h0=*/data_0.parquet` — **H3 resolution 9**, parent rollups 8,7,6,5 as columns, partitioned by `h0`. `carbon` = total Mg C per cell (area-integrated density). These are the paths the STAC assets reference.
- **COGs:** `public-carbon/v2/cogs/{category}_c_total_{year}.tif` — carbon **density** Mg C ha⁻¹, ZSTD.
- Products: irrecoverable {2018,2022,2023,2024}; vulnerable & manageable {2010,2018,2024}. Irrecoverable 2010 is absent (corrupt source TIFF — see `irrecoverable-2010-gdal-bug.md`).

> The `v2/{dataset}/hex/` prefix and the old `move-hex-to-v2.yaml` step are **retired**.
> Earlier builds wrote hex under `v2/`; the canonical area-integrated rebuild (#202) lives
> at the top-level `{dataset}/hex/` paths, so the `v2/` hex copies, a stale `hex-h9-sum/`
> tree, legacy US-only `hex/us-*.parquet`, the v1 `irrecoverable-carbon/hex/`, and
> `v2/raw/` were all purged in #330 (~280 GB). Do not recreate the `v2/` hex copies.

## Processing Steps

### 1. COG Preprocessing (custom — not generated by cng-datasets)
`preprocess-cogs.yaml` / `individual-cog-jobs/` — downloads source TIFFs from Zenodo and converts to ZSTD COGs in `public-carbon/v2/cogs/`. Required because `cng-datasets raster-workflow` reads from S3, not directly from Zenodo.

### 2. Hex Workflows (generated by cng-datasets raster-workflow)
Ten per-dataset directories (`{dataset}/`) each contain the generated workflow YAML, written to the canonical top-level `{dataset}/hex/`. The source rasters are carbon **density** (Mg C ha⁻¹), so hexing area-integrates density × pixel area → total Mg C per cell (#202; an earlier `sum`-on-density build under-reported totals ~6–7× and was replaced).

### 3. Validation (`validate-cog-integral.yaml`, #330)
Independent full-resolution COG area-integral (`Σ density × pixel_area_ha`, nodata-masked) compared to hex `SUM(carbon)`. Result: hex matches the integral to a uniform **+0.22%** on all 10 layers (benign H3-cell-area vs exact-pixel offset). Notes:
- These straight integrals run **~2–3% above** CI's published committed-loss headline (irrecoverable 2024 = 131.9 Gt here vs CI's 128.0 Gt; CI corrected the 2018 baseline 139.1 → 135.3 Gt).
- The per-year series is **not strictly monotonic** in a raw integral — this is in CI's shipped rasters, not our pipeline. Cite CI's summary for committed-loss change figures.
