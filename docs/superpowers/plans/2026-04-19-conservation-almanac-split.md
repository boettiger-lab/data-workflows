# conservation-almanac-2024 → sites + funding Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the single `conservation-almanac-2024` collection (one row per funding transaction, site attributes duplicated) into two clean collections: `conservation-almanac-2024-sites` (one row per `tpl_id`, spatial) and `conservation-almanac-2024-funding` (long transaction table, tabular-only), linked by `tpl_id`.

**Architecture:** One k8s preprocessing Job reads the raw TPL parquet and writes two deduped parquets to S3 (sites with geometry, funding as a long table, no geometry). Sites runs through the normal `cng-datasets workflow` pipeline to produce GeoParquet + PMTiles + H3 hex. Funding is published as a tabular-only STAC asset — no PMTiles, no hex, no geometry. Both new collections live in `public-tpl/` alongside the existing flat collection, which stays in place with a "superseded" note in its description for backwards compat with any downstream consumers we haven't yet migrated.

**Tech Stack:** DuckDB for the split (follows `catalog/pad-us/k8s/extract-lookup-tables.yaml` precedent), `cng-datasets workflow` for the sites pipeline, direct rclone upload for funding parquet + STAC.

**Bucket / Canonical path reminders (AGENTS.md hard boundaries):**
- STAC lives on NRP S3 under `s3://public-tpl/`, NOT in this repo. Edit in `/tmp/`, rclone up.
- Never touch the `cng-datasets` tool — if a tool bug blocks us, file an MRE issue on `boettiger-lab/datasets`.

**Open-row-grain facts (verified on live parquet 2026-04-18):**
- 90,068 rows, 67,428 unique `tpl_id` (16,456 with >1 funding row).
- 218 `tpl_id`s (0.32%) have minor within-site attr variation — handled by `FIRST_VALUE ORDER BY fid` dedup.
- Site attrs confirmed constant per `tpl_id` for `state_id`, `state`, `site`, `acres`.
- Funding tuples: 89,237 distinct `(tpl_id, program, sponsor, amount)` — so near-unique by those keys.

## Task 1: Preprocess Job — split raw parquet into sites + funding

**Files:**
- Create: `catalog/tpl/k8s/split/preprocess-split.yaml`

**Design notes:**
- Uses the existing `ghcr.io/boettiger-lab/datasets:latest` image (already has duckdb-spatial).
- Uses the standard NRP Ceph env vars (see `extract-lookup-tables.yaml`). Reads raw via `https://s3-west.nrp-nautilus.io/public-tpl/raw/conservation-almanac-2024.parquet` (public), writes output via `s3://public-tpl/...` (needs AWS creds from `aws` secret).
- Single-container Job, `completions: 1`, `parallelism: 1`.
- RAM: 32Gi (the raw parquet is small, but ORDER BY + COPY may spill). Ephemeral storage: 50Gi (namespace max).
- Dedup rule for sites: one row per `tpl_id`, keeping values from the row with smallest `fid` — deterministic, and preserves the upstream first-encounter ordering.

- [ ] **Step 1: Write the job YAML**

Create `catalog/tpl/k8s/split/preprocess-split.yaml`:

```yaml
apiVersion: batch/v1
kind: Job
metadata:
  name: tpl-split-preprocess
  namespace: biodiversity
spec:
  completions: 1
  parallelism: 1
  backoffLimit: 2
  template:
    metadata:
      labels:
        app: tpl-split-preprocess
    spec:
      priorityClassName: opportunistic
      restartPolicy: Never
      containers:
      - name: split
        image: ghcr.io/boettiger-lab/datasets:latest
        imagePullPolicy: Always
        env:
        - name: AWS_EC2_METADATA_DISABLED
          value: "true"
        - name: AWS_S3_ENDPOINT
          value: "rook-ceph-rgw-nautiluss3.rook"
        - name: AWS_PUBLIC_ENDPOINT
          value: "s3-west.nrp-nautilus.io"
        - name: AWS_HTTPS
          value: "false"
        - name: AWS_VIRTUAL_HOSTING
          value: "FALSE"
        envFrom:
        - secretRef:
            name: aws
        resources:
          requests:
            memory: 32Gi
            cpu: "4"
            ephemeral-storage: 50Gi
          limits:
            memory: 32Gi
            cpu: "4"
            ephemeral-storage: 50Gi
        command: ["/bin/bash", "-c"]
        args:
        - |
          set -euo pipefail
          python3 <<'PYEOF'
          import duckdb
          c = duckdb.connect()
          c.execute("INSTALL spatial; LOAD spatial;")
          c.execute("INSTALL httpfs; LOAD httpfs;")
          c.execute("""
            CREATE SECRET s3_public (
              TYPE S3,
              KEY_ID '{}',
              SECRET '{}',
              ENDPOINT 'rook-ceph-rgw-nautiluss3.rook',
              URL_STYLE 'path',
              USE_SSL false
            )
          """.format(__import__('os').environ['AWS_ACCESS_KEY_ID'],
                     __import__('os').environ['AWS_SECRET_ACCESS_KEY']))

          SRC = "s3://public-tpl/raw/conservation-almanac-2024.parquet"

          # Sanity pre-check
          n_rows, n_tpl = c.execute(
            f"SELECT COUNT(*), COUNT(DISTINCT tpl_id) FROM read_parquet('{SRC}')"
          ).fetchone()
          print(f"[pre] rows={n_rows} unique tpl_id={n_tpl}")
          assert n_rows >= 90000 and n_tpl >= 67000, "raw shape unexpected"

          SITE_COLS = [
            "tpl_id","state_id","state","county","municipality","site","acres",
            "year","date","owner","owner_type","manager","manager_type",
            "purchase_type","easement","easement_type","access_type",
            "purpose_type","duration_type","comments","geom","bbox"
          ]
          site_select = ", ".join(
            f"FIRST({col} ORDER BY fid) AS {col}" for col in SITE_COLS if col != "tpl_id"
          )

          # --- Sites: one row per tpl_id ---
          c.execute(f"""
            COPY (
              SELECT tpl_id, {site_select}
              FROM read_parquet('{SRC}')
              GROUP BY tpl_id
            ) TO 's3://public-tpl/conservation-almanac-2024-sites.parquet'
            (FORMAT PARQUET, COMPRESSION ZSTD)
          """)

          # --- Funding: long table, no geometry ---
          c.execute(f"""
            COPY (
              SELECT tpl_id, program_id, program, sponsor_id, sponsor,
                     sponsor_type, amount,
                     data_provider, data_source, source_date, data_aggregator
              FROM read_parquet('{SRC}')
              WHERE program IS NOT NULL OR sponsor IS NOT NULL OR amount IS NOT NULL
            ) TO 's3://public-tpl/conservation-almanac-2024-funding.parquet'
            (FORMAT PARQUET, COMPRESSION ZSTD)
          """)

          # Post-checks
          n_sites = c.execute(
            "SELECT COUNT(*) FROM read_parquet('s3://public-tpl/conservation-almanac-2024-sites.parquet')"
          ).fetchone()[0]
          n_sites_u = c.execute(
            "SELECT COUNT(DISTINCT tpl_id) FROM read_parquet('s3://public-tpl/conservation-almanac-2024-sites.parquet')"
          ).fetchone()[0]
          n_fund = c.execute(
            "SELECT COUNT(*) FROM read_parquet('s3://public-tpl/conservation-almanac-2024-funding.parquet')"
          ).fetchone()[0]
          print(f"[post] sites rows={n_sites} unique={n_sites_u} funding rows={n_fund}")
          assert n_sites == n_sites_u, "sites parquet not unique by tpl_id"
          assert n_sites == n_tpl, "sites count differs from raw tpl_id count"
          print("OK")
          PYEOF
```
